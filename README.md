# مشروع تسبيح Android — إنشاء APK عبر GitHub Actions

يتضمن هذا المشروع تطبيق Android، وملف GitHub Actions لبناء نسخة Debug APK تلقائياً.

## إنشاء ملف APK
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد إلى الفرع `main` (يجب أن يكون مجلد `.github` ضمن الملفات المرفوعة).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Tasbeeh APK** ثم **Run workflow**، أو انتظر انتهاء البناء بعد رفع الملفات إلى `main`.
5. افتح تشغيل الـ workflow الذي انتهى بنجاح، ثم نزّل **Artifacts → tasbeeh-debug-apk**.
6. فك ضغط الملف الذي تم تنزيله؛ ستجد `app-debug.apk`.

## ملاحظات
- هذه نسخة Debug للتجربة والتثبيت، وليست نسخة Release موقّعة للنشر على Google Play.
- يتطلب البناء اتصال GitHub بالإنترنت لتنزيل Android SDK وGradle والتبعيات.
- عند تثبيت APK يدوياً على الهاتف، قد تحتاج إلى السماح بالتثبيت من هذا المصدر.
